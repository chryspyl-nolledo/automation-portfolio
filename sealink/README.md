# SeaLink Ship Spares (demo) — Odoo logistics

A fictional ship-spares supplier (warehouse MNL) delivering to vessels. Odoo is the source of truth; n8n turns it into a daily brief.

Sample data: `data/sealink_spare_parts.csv` (14 `SP-` items), `sealink_opening_stock.csv`, `sealink_contacts.csv` (4 vessels, 2 suppliers).
